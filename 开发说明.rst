发布到塔尔旺公司maven仓库
==============================================

选择 **releaseTelecwin** profile 然后执行 **deploy** 阶段。

需要用 JDK15，在 cmd 中执行，如果是 powershell 那么参数要加双引号。

    mvn "-Dmaven.test.skip=true" -PreleaseTelecwin clean deploy

maven 教程
==============================================

Maven通过lifecycle、phase和goal来提供标准的构建流程。

最常用的构建命令是指定phase，然后让Maven执行到指定的phase::

    mvn clean
    mvn clean compile
    mvn clean test
    mvn clean package

通常情况，我们总是执行phase默认绑定的goal，因此不必指定goal。

详细内容请参考 maven教程_.
